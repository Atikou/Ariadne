# 桌面 UI 重构验收记录

日期：2026-09-05。目标仍是整体结构、页面与动画优化；本文件记录阶段证据，不代表全部完成。

## 设计约束

- 桌面 AI 工作台：对话优先，工具按需打开；保留 Dockview 停靠、独立窗口与已保存布局。
- 业务状态继续由 Runtime / Public Projection 拥有；视觉重构不伪造任务、进度和消息。
- 控件切换状态不改变外部几何尺寸；标题、操作区、滚动区各自保持稳定。
- 正文与操作标签优先可读，11–12px 用于辅助说明，避免大面积 9px 文字。
- 反馈动画使用短 tween；不在面板尺寸上持续添加弹簧动画，尊重系统减少动态效果偏好。
- 不修改凭据、权限、用户内容或无关的并行 Runtime 工作。

## 已落地

- 主导航仅标记当前模块；标题取当前会话；命令入口在标题栏的可用区域居中。
- 对话侧栏可收起；移除对话区内多余的圆角框；空会话提示靠近输入框。
- 按用户最新反馈，空会话不再为输入框下方分配弹性留白；与有消息时共用三行布局，输入框始终水平居中、距会话区域底部 20px，长草稿向上增长。
- 麦克风、发送、停止采用共同的 29px 边界、圆角与无阴影规则。Electron 独立渲染测量覆盖浅色/深色、正常/禁用状态。
- 标签操作区固定为 40px，不再在悬停时改变标题宽度；标签后续采用下述完整槽位布局。
- 标签后续根因修正：当前 Dockview 初始横栏没有 `.dv-horizontal`，旧尺寸规则未命中。改为使用真实 `aria-orientation`，横向滚动视口分配完整等宽槽位（156px 阅读基准），通过局部滚动吸附避免边缘停留半枚标签；不修改库文件、不重排面板、不重置布局。自适应宽度变化时，仅滚动活动标签所属栏以保持其可见，竖向栏不应用横向槽位规则。
- 使用 Dockview 正式分组标题操作接口提供“全部标签”入口，展示当前分组数量和完整列表；禁用原生不可聚焦的溢出入口，移除旧溢出专用标签分支与样式。统一复用 SelectMenu 的方向键、Home/End、Enter、Escape、Tab 和焦点恢复，标签重命名/关闭同步更新列表与计数。
- 下拉弹层、测量、滚动监听与尺寸观察器跟随控件的 ownerDocument/defaultView，支持独立窗口及原生 dialog。关闭后在 React 布局提交阶段恢复焦点；选项导航只滚动自身菜单，补齐子菜单方向键的实际焦点移动。
- 主题统一沿用 Dockview 会传入独立窗口的单一标准主题类，移除额外私有类造成的样式丢失。活动标签布局观察器在停靠位置变化后重新绑定所属窗口，独立窗口首次打开和调整尺寸均保持活动标签完整可见。
- 模块标签菜单补齐初始焦点、方向键和 Escape 焦点恢复。
- 命令入口采用原生模态 dialog，提供中文筛选、方向键选择、Enter 打开、Escape 关闭、空结果与加载提示；技能仍为只读预览，异步响应按请求代次隔离。
- 命令结果列表只滚动自身，不使用会影响祖先容器的滚动 API。
- 设置页提高导航、输入与说明字号，减少嵌套卡片；类别切换重置内容滚动并淡入，表单草稿仍由 SettingsPanel 持有。
- 弹层采用 120–180ms 的透明度/位移 tween，复用全局减少动画规则。
- 工具输出改为列表/详情双区，680px 以下使用可返回的单区阅读；两区独立滚动，加载和分页结果按请求代次处理，切换会话时销毁旧详情状态。
- 文件浏览使用可聚焦的语义树，支持上下、左右、Home/End 和 Enter；补齐根目录加载、未选工作区、空文件夹和读取错误，仍只使用已有目录浏览 API。
- 日志工具栏分离标题/元数据与筛选操作，移除日志行的固定最小宽度；工具、文件、日志、计划和任务面板共享统一空态。
- Agent 状态只选择当前会话的根任务，优先活动任务、其次最新历史任务；未选择会话时不展示其他会话的旧任务，未提供进度时不填造百分比。
- 工具、文件与日志样式回归各自模块，不再堆入 app/styles.css。新增独立 Electron 交互夹具，不连接用户 Runtime 或读取用户内容。
- 设置、确认、重命名与命令弹窗统一使用原生模态生命周期；移除设置页捕获阶段的全局 Escape/Tab 处理，由浏览器限制背景焦点。共享焦点恢复支持嵌套弹窗，不抢占替换弹窗的焦点。
- 下拉菜单渲染在所属原生 dialog 中，保持顶层可见和可聚焦；Escape 先关闭菜单，Tab/Shift+Tab 回到表单相邻控件。重命名每次打开重建输入草稿并选中新名称，避免上次草稿与选区残留。
- 设置页拆分查询容器 `.settings-panel` 与内部布局 `.settings-layout`，修正容器查询不能修改容器自身的错误；窄布局侧栏真正从 210px 缩为 164px / 62px，分类按钮保留可访问名称。
- 任务页固定标题与底部操作区、正文独立滚动，辅助文字提高到 12px；执行失败在活动列表中有明确文字和状态符号，已有进度使用短 tween 更新。移除 header 的泛化 span 样式，避免把状态胶囊压成 9px。
- 任务页修正 projection 来源判断反向的问题，显示已存在且由服务继续校验的取消/预算/恢复入口。操作期间防重复提交，失败留在页面；切换任务重建局部状态，旧错误不混入新任务。
- 计划页只展示当前会话的计划，区分待确认/已批准/已拒绝/已过期；补齐提交中、失败和不可批准原因。计划正文减少嵌套卡片，提高长文可读性。
- 终端采用可换行工具栏和弹性内容区，恢复提示不再挤占错误的 grid 行。启动期间禁用输入/重复重启，运行中终端重启前确认；失败状态调整窗口也会同步画布，但不向已结束进程发送 resize。
- 任务、计划正文/面板、终端的样式分别拆回模块 CSS；保留已有 xterm 与 Runtime/Preload 服务边界，不执行真实取消、批准或终端重启来做验证。
