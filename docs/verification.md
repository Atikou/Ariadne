# 验证说明

## 自动验证

```powershell
npm run typecheck
npm test
npm run build
```

验证重点：

- 源码中没有 Runtime/Agent 后端、子进程或本地 HTTP Server 实现；
- 原桌面壳的内置模块、Mock 状态和交互效果完整保留；
- Renderer 不能直接访问 Node.js、剪贴板或任意 IPC；
- CSP 不允许任意网络连接；
- 工作区文件路径不能逃逸配置根；
- 终端会话按 Renderer 所有权创建、切换和回收；
- 桌面偏好和布局可以持久化；
- 生产构建只产出 Electron app。

## 手工检查

1. 启动应用，确认 Chat、会话、Agent 状态、执行计划、工具输出、日志和权限模块仍在，并可通过本地 Mock 场景切换状态。
2. 在 Chat 中确认对话标尺、滚动跟随、跳转最新消息，以及悬停消息后显示时间、复制和改写操作。
3. 打开重置布局弹窗，确认页面没有黑色半透明遮罩。
4. 切换浅色主题，确认所有 Dockview 标签、圆角和分隔条跟随主题，没有深色标签块或黑色竖条。
5. 打开文件模块，确认只能浏览配置的工作区目录。
6. 打开终端，切换 PowerShell/CMD，确认已有会话保持挂载。
7. 修改主题和桌面偏好，重启后确认恢复。
8. 调整 Dockview 布局并重启，确认布局恢复。
9. 退出应用后确认终端和托盘进程被正常释放。

当前不执行 Runtime、模型、协议兼容、流式事件、Worker 或双项目联调测试，因为这些功能尚未接入。
