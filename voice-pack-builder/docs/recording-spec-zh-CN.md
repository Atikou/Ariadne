# 普通话单人音色录音规范

- 录音者必须同意本地训练和使用；`MODEL_CARD.md` 记录授权范围，默认禁止再分发。
- 使用同一麦克风、房间、增益和嘴到麦克风距离；关闭降噪、混响、音乐及系统提示音。
- 原始录音可为 WAV 16/24-bit；准备流程统一转为 22050 Hz、16-bit、单声道 PCM。
- 每段 2–12 秒，只包含一句话；开头和结尾保留约 100–300ms 自然静音，不截断辅音或尾音。
- 文字稿必须逐字对应实际发音，数字、日期、英文和语气词按实际读法记录。
- 建议 30–60 分钟干净语音，覆盖声母、韵母、四声、轻声、儿化、数字、日期和常用英文缩写。
- 目录固定为 `metadata.csv` 与 `wav/`；每行格式为 `文件名.wav|准确文字稿`。
- 先运行 `ariadne-voice dataset prepare`，再运行 `ariadne-voice dataset validate`；任何缺失、声道、采样率或时长错误都必须修复后才能训练。
